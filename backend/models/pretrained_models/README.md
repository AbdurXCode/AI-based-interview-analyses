# Pretrained models (video analysis)

Heavy files here (`.h5`, `.dat`, `.pkl`) are **gitignored** so the repo stays small on GitHub.

For local **feature video analysis**, place your artifacts in this directory or use **Git LFS** / your own hosting, and align paths with `body_language_driver` / gaze code expectations.

See `backend/README.md` (`FEATURE_VIDEO_ANALYSIS`, cwd notes).
